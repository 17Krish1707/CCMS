Schedule Case Hearing

Select a registered case and preferred slot. Check availability to prevent judge and courtroom conflicts.

Sequence Diagram Workflow Followed:

  1. Clerk selects case & enters date, time, judge, courtroom
  2. System checks Judge availability
  3. System checks Courtroom availability
  4. If conflict detected → Displays specific conflict reason
  5. If available → Enables confirmation step
  6. Clerk confirms → System creates Hearing, sets status to Scheduled
  7. System displays simulated notification to Judge, Lawyer, Defendant, and Witnesses
